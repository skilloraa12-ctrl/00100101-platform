# 00100101 — українська навчальна платформа програмування

> **Продовжуєш у Claude Code чи в новому чаті?** Прочитай спершу

«Від першого символу до власного Full Stack продукту.»

Повністю робочий React + Vite застосунок. Не макет — реальний редактор коду,
реальна перевірка завдань, реальний прогрес (зберігається в браузері).

## Що вже є

- **HTML (15 уроків), CSS (9), JavaScript (9), English for IT (10)** — теорія →
  приклад → завдання → редактор коду / текстова відповідь → **реальна
  перевірка**: DOMParser для HTML, regex-перевірка правил для CSS, sandboxed
  iframe + автотести для JS, звірка відповіді для English. JS-курс
  завершується міні-проєктом «список справ» (DOM + події + `createElement`).
- **Символи** (~80 записів, без дублів) — таблиця-плитка на кшталт періодичної:
  тисни на символ, знизу з'являється пояснення. Покриває базову пунктуацію,
  дужки, оператори, складені оператори (`+=`, `++`, `=>`, `...`), escape-
  послідовності, CSS-комбінатори, HTML-специфічні (`<!DOCTYPE>`, `<!-- -->`),
  бітові оператори, Python-специфічні (`//`, `:=`, `@decorator`), SQL-
  специфічні (`<>`, `||`, `::`, `--`).
- **Бібліотека** — тепер 5 розділів: HTML (27 тегів), CSS (23 властивості), JavaScript (22 концепції), Python (12), SQL (12). Ключові терміни (**Array, Object, Flexbox, Form, List, SELECT, Input, Label, List(HTML), Header, Nav, Main, Footer, Section** — 14 усього) відкриваються через кнопку «Детальніше, з прикладами» в багатий покроковий формат: іконка + назва, блок «Просто кажучи», пронумеровані кроки з кодом і результатом виконання, і секція «Де використовують». Решта термінів поки в компактному вигляді — формат легко розширити на будь-який інший запис через об'єкт `TERM_GUIDES` (див. нижче).
- **34 повних гайдів** (код + результат виконання, покроково) розкидані по бібліотеці й шпаргалках: Array, Object, Flexbox, Form, List, SELECT, 8 HTML-тегів (Input, Label, List, Header, Nav, Main, Footer, Section), і по 2 з кожної з 10 категорій шпаргалок — reduce(), Promise (JS); position, Grid (CSS); `<table>`, `<img>` (HTML); git rebase, merge conflict (Git); chmod, grep (термінал); PUT vs PATCH, CORS (HTTP); lookahead, флаги (Regex); мультикурсор, палітра команд (VS Code); list comprehension, try/except (Python); JOIN, GROUP BY+HAVING (SQL).
- **Шпаргалки** (10 категорій, включно з Python і SQL) — щільні довідкові таблиці; термін з підкресленням клікабельний і веде до гайду з попереднього пункту:
  - **HTML**: майже повний перелік тегів (структура, текст, форми, таблиці,
    медіа, інтерактивність, застарілі теги з приміткою «уникай»), плюс
    глобальні атрибути (`id`, `class`, `data-*`...) і ARIA-атрибути доступності.
  - **CSS**: властивості (box model, layout, текст, фон/ефекти), псевдокласи
    й псевдоелементи (додатково), одиниці виміру, функції (`calc`, `clamp`,
    `rgb`...), логічні властивості, `@`-правила.
  - **JavaScript**: методи масивів/рядків/об'єктів/Math (як було) + DOM
    (пошук, створення, вміст, атрибути), події, Promise/fetch, Map/Set.
  - **Python** (нове) — ключові слова, типи, рядки, списки/словники, ООП,
    винятки й стандартна бібліотека.
  - **SQL** (нове) — команди, уточнення SELECT, умови, JOIN, агрегатні
    функції, структура таблиці, типи даних.
  - Git, Термінал/Linux, HTTP-статуси, Regex, гарячі клавіші VS Code — як
    було.
- **English for IT та Українська термінологія** — і як окремий інтерактивний
  курс (English for IT, 10 уроків з перевіркою відповіді), і як довідникові
  словники (~50 та ~35 записів).
- **«Де ще можна виконувати завдання»** — на сторінці кожного курсу є список
  реальних зовнішніх інструментів (CodePen, StackBlitz, Replit, VS Code,
  python.org, Docker...) з позначками «безкоштовно» / «freemium» / «платно».
- **Глобальний пошук** — одночасно по уроках, бібліотеці, шпаргалках,
  символах, словниках.
- **Прогрес, XP і досягнення** — зберігаються в `localStorage` браузера, між
  сесіями, нараховуються по-справжньому (без фейкових кнопок).

Python, SQL, Frontend, Backend, Full Stack позначені як «у розробці» — чесно,
без заглушок, що вдають завершені уроки.

## Встановлення й запуск

Потрібен [Node.js](https://nodejs.org) (версія 18 або новіша).

```bash
npm install
npm run dev
```

Відкриється посилання (зазвичай `http://localhost:5173`) — це і є платформа.

Зібрати продакшн-версію (статичні файли для будь-якого хостингу):

```bash
npm run build
npm run preview   # перевірити зібрану версію локально
```

## Структура проєкту

```
00100101/
├── index.html            вхідна HTML-сторінка
├── package.json
├── vite.config.js
├── tailwind.config.js
├── postcss.config.js
├── src/
│   ├── main.jsx           точка входу React
│   ├── App.jsx             весь застосунок: дані курсів, бібліотека,
│   │                        символи, шпаргалки, компоненти, логіка перевірки
│   └── index.css           підключення Tailwind
└── README.md
```

Весь застосунок навмисно лежить в одному `src/App.jsx` (дані + компоненти),
щоб було просто побачити всю структуру одразу. Коли проєкт виросте, дані
(масиви уроків, бібліотеки, символів) можна винести в окремі файли під
`src/data/` — компоненти імпортують їх без змін логіки.

## Як додати новий урок

Кожен урок — об'єкт цієї форми (в масивах `HTML_LESSONS`, `CSS_LESSONS`,
`JS_LESSONS` або `ENGLISH_LESSONS` у `src/App.jsx`):

```js
{
  id: "html-16",
  title: "Назва уроку",
  theory: "Текст теорії...",
  example: { code: "...", explain: "..." },
  task: "Опис завдання",
  starter: "код-заготовка",
  hints: ["підказка 1", "підказка 2", "підказка 3"],
  solution: "готовий код",
  type: "html" | "css" | "js" | "vocab",
  check: (doc, raw) => ({ pass: true/false, message: "..." }), // для html
  tests: [{ re: /.../, msg: "..." }],                          // для css
  testCode: "return {pass:true, message:''}",                  // для js (sandbox)
  accepted: ["правильна відповідь", "варіант 2"],               // для vocab
}
```

Додай об'єкт у відповідний масив — сайдбар, прогрес і перевірка підхоплять
його автоматично, нічого більше міняти не треба.

## Як додати покроковий гайд для терміна бібліотеки

Формат «Масив (Array)» зі скріншота — це об'єкт у `TERM_GUIDES`:

```js
"js-array": {
  accent: "violet", // колір: violet, sky, teal, orange, lime, cyan, rose, amber
  titleEn: "Array",
  titleUa: "Масив",
  intro: "Пояснення абзацом.",
  simple: "Пояснення \"просто кажучи\", одне речення.",
  steps: [
    { title: "Крок 1", code: "...", resultLabel: "Результат:", result: "...", note: "необов'язкова примітка" },
    // ще 3-5 кроків
  ],
  usage: ["де використовують", "..."],
}
```

Потім додай `guide: "js-array"` до відповідного запису в `LIBRARY_*` — кнопка
«Детальніше, з прикладами» з'явиться на картці автоматично.

## Як додати новий курс

1. Створи масив уроків (як `PYTHON_LESSONS`) за схемою вище.
2. Додай новий тип уроку в `LessonView`, якщо існуючі (`html`/`css`/`js`/
   `vocab`) не підходять — там же живе вся логіка перевірки.
3. Додай курс у масив `COURSES` з `status: "available"`.
4. За бажанням додай інструменти в `TOOLS_BY_COURSE[courseId]`.

## Технічне обмеження, яке варто знати

Прогрес зараз зберігається в `localStorage` браузера — він персональний для
кожного пристрою й не синхронізується між ними. Якщо захочеш прогрес, який
доступний з будь-якого пристрою (наприклад, вхід через акаунт), знадобиться
справжній бекенд + база даних — це і є етапи 9–10 дорожньої карти.
